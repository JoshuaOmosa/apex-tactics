# ApexTactics: 2D Tactical Pathfinding

A high-performance navigation system built in **Godot 4.3** demonstrating A* pathfinding and tactical movement.

##  Project Goals
- Implement **NavigationAgent2D** for intelligent obstacle avoidance.
- Design a **Point-and-Click** movement system with vector math.
- Utilize **TileMapLayer** for grid-based environment design.
